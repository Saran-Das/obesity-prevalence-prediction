# Dataset Instructions

The raw datasets used in this project are not included in the GitHub repository.

## Adult Obesity Dataset

Dataset:

**Nutrition, Physical Activity, and Obesity – Behavioral Risk Factor Surveillance System**

Source:

https://catalog.data.gov/dataset/nutrition-physical-activity-and-obesity-behavioral-risk-factor-surveillance-system

Save the downloaded dataset as:

```text
Obesity_adult.csv
```

## Childhood Obesity Dataset

Dataset:

**Nutrition, Physical Activity, and Obesity – Women, Infant, and Child**

Source:

https://catalog.data.gov/dataset/nutrition-physical-activity-and-obesity-women-infant-and-child

Save the downloaded dataset as:

```text
Obesity_child.csv
```

Refer to the project notebooks for the expected data-loading paths and preprocessing workflow.

The datasets should be obtained from their original public sources rather than redistributed through this repository.
